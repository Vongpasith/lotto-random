# lotto-random

ເວັບສຸ່ມຫວຍຈາກສະຖິຕິຜົນຫວຍ 6 ໂຕ ຍ້ອນຫຼັງ

- ເປີດ `index.html` ໃນບຣາວເຊີໄດ້ເລີຍ ບໍ່ຕ້ອງຕິດຕັ້ງຫຍັງ
- ຜົນຫວຍຢູ່ໃນໄຟລ໌ `lotto_result` ແຖວລະງວດ ເປັນ `ເລກ6ໂຕ ວັນທີ` ເຊັ່ນ `435208 2026-10-21` (ງວດເກົ່າ → ງວດໃໝ່) — ແກ້ແລ້ວແລ່ນ `./update-data.sh` ເພື່ອສ້າງ `data.js` ໃໝ່

## ວິທີຄຳນວນ
- ນັບວ່າເລກ 0–9 ອອກຈັກຄັ້ງໃນແຕ່ລະຫຼັກ ແລ້ວແປງເປັນຄວາມເປັນໄປໄດ້ `(ຈຳນວນຄັ້ງ + 1) / (ຈຳນວນງວດ + 10)`
- ສຸ່ມເທື່ອລະຫຼັກ ໂດຍຖ່ວງນ້ຳໜັກຕາມຄວາມເປັນໄປໄດ້ນັ້ນ (ໂໝດເລກຮ້ອນ = ຍົກກຳລັງ 3, ເລກເຢັນ = ກັບດ້ານ)
- "ຄະແນນສະຖິຕິ" = ຜົນຄູນຂອງຄວາມເປັນໄປໄດ້ແຕ່ລະຫຼັກ ທຽບກັບການສຸ່ມລ້ວນ (1.00x = ເທົ່າຄ່າສະເລ່ຍ)

> ຫວຍແຕ່ລະງວດສຸ່ມແຍກກັນ ໂອກາດຖືກ 6 ໂຕ ຂອງທຸກເລກແມ່ນ 1 ໃນ 1,000,000 ສະເໝີ ໃຊ້ເພື່ອຄວາມມ່ວນເທົ່ານັ້ນ
